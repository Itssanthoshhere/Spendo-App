SPENDO PROJECT & ARCHITECTURE STATUS
====================================

This file documents the stack options, repository configuration, and current
integration status for the `spendo` project.

Selected Stack Options
----------------------

- Project name: `spendo`
- Frontend: `native-uniwind` (React Native 0.88.1, Expo SDK 58, Expo Router, Uniwind / HeroUI Native)
- Backend: `hono` (Server-side HTTP API running on port 3000)
- Runtime and package manager: `bun` (v1.3.9)
- Authentication: `better-auth` (with Expo plugin and PostgreSQL Drizzle adapter)
- Database: `postgres` hosted on Supabase (Pooler transaction mode on port 6543)
- ORM: `drizzle-orm` (managed via `@spendo/db` with Drizzle Kit)
- Monorepo tooling: `turborepo`
- Environment management: `varlock` with type generation across packages and apps
- Version control: Git (default branch: `main`, remote: `https://github.com/Itssanthoshhere/Spendo-App.git`)

Current Integration Status
--------------------------

1. Supabase & Drizzle Database:
   - Configured in `apps/server/.env` with Supabase pooler connection.
   - Auth tables (`user`, `session`, `account`, `verification`) applied and verified with `drizzle-kit push`.
   - User table extended with onboarding & profile columns (`onboarding_completed`, `country`, `phone`, `currency`).
   - Migration & push scripts: `bun run db:push`, `bun run db:generate`, `bun run db:migrate`.

2. Mobile App (Expo & React Native):
   - Aligned to React Native `0.88.1` to resolve native `RCTStatusBarAppearance` symbol resolution with `ExpoModulesCore`.
   - iOS development client (`spendo.app`) compiled and installed on the iOS Simulator.
   - Running live with Hot Module Reloading through Metro at `http://localhost:8081`.
   - Core Expo plugins & native modules configured and linked:
     * `expo-font`: custom font loader (`@expo-google-fonts/plus-jakarta-sans` loaded in `_layout.tsx`)
     * `expo-image`: high-performance image component with SDWebImage native caching
     * `expo-router`: file-based navigation and routing
     * `expo-secure-store`: encrypted storage for auth sessions & secure tokens
     * `@react-native-community/datetimepicker`: native iOS/Android date-time picker dialogs
     * `expo-sharing`: native document/file sharing sheet
   - Native iOS CocoaPods artifacts integrated and linked via `pod install`.
   - Cashory design system theme integrated into `apps/native/global.css` with semantic color tokens, light/dark mode palettes, and HeroUI Native component styles.

3. Backend API (Hono):
   - Runs at `http://localhost:3000`.
   - Connected to Better-Auth and Drizzle database service.

Reproducible Scaffold Command
-----------------------------

```sh
cd ~/Developer/Projects

bun create better-t-stack@latest spendo \
  --frontend native-uniwind \
  --backend hono \
  --runtime bun \
  --api none \
  --auth better-auth \
  --payments none \
  --database postgres \
  --orm drizzle \
  --db-setup supabase \
  --package-manager bun \
  --git \
  --web-deploy none \
  --server-deploy none \
  --install \
  --addons turborepo \
  --examples none
```

Daily Development Workflow
--------------------------

- Run both API server and mobile bundler:
  `bun run dev`
- Run only the server:
  `bun run dev:server`
- Run only the mobile app:
  `bun run dev:native`
- Sync database schema to Supabase:
  `bun run db:push`
- Type checking across all workspaces:
  `./node_modules/.bin/tsc -p apps/server/tsconfig.json --noEmit`
